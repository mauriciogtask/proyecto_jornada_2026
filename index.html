Generador de Tarjetas de Presentación

Cargá un CSV con las columnas nombre, whatsapp, mail, linkedin e instagram (las dos últimas opcionales), o pegá el contenido directamente. Cada fila se convierte en una tarjeta de presentación con un estilo visual asignado al azar.

Opción 1 — Subir archivo CSV

Arrastrá tu archivo CSV acá o hacé clic para elegirlo

Se aceptan archivos .csv con las columnas: nombre, whatsapp, mail, linkedin (opcional) e instagram (opcional).

Opción 2 — Pegar el contenido CSV

Código QR de esta página

📦 El .zip trae una carpeta tarjetas/ con un archivo por persona y un index.html con los enlaces, listo para subir tal cual a un repositorio de GitHub, activar GitHub Pages, y que cada tarjeta quede disponible en una URL tipo https://usuario.github.io/repo/tarjetas/nombre-apellido.html.

📄 El botón “Cargar ejemplo” lee el archivo personas.csv ubicado en el mismo directorio que este HTML e incluye a todas las personas que figuren ahí.

ℹ️ Las columnas linkedin e instagram son opcionales: si una fila no las trae (o vienen vacías), la tarjeta de esa persona simplemente no muestra el chip correspondiente.

Los estilos de tarjeta se asignan al azar. Usá el dado 🎲 de cada tarjeta para probar otras variantes.
