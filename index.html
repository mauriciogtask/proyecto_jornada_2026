Generador de Tarjetas de Presentación

Cargá un CSV con las columnas nombre, whatsapp y mail (subiendo un archivo o pegando el contenido). Cada fila se convierte en una tarjeta de presentación digital con un estilo visual elegido al azar entre 6 temas, lista para compartir o descargar.

Opción 1 — Subir archivo CSV

Arrastrá tu archivo .csv acá o hacé clic para elegirlo

Opción 2 — Pegar el contenido CSV

El .zip trae una carpeta tarjetas/ con un archivo por persona y un index.html con los enlaces. Subilo tal cual a un repositorio de GitHub, activá GitHub Pages, y cada tarjeta queda disponible en una URL tipo https://usuario.github.io/repo/tarjetas/nombre-apellido.html.

“Cargar ejemplo” lee el archivo personas.csv ubicado en el mismo directorio que este HTML e incluye a todas las personas que figuren ahí.
